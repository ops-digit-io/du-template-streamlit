# du-template-streamlit

PoC template · **Streamlit app (Python)**.

A data app in pure Python — KPIs, trend, and a breakdown from a CSV extract.

Follows [streamlit/app-starter-kit](https://github.com/streamlit/app-starter-kit). Used by the digitalization
portal's PoC builder via GitHub "generate from template" — the portal creates a
use-case repository from this template, then overlays the case's own files.

Run locally: `streamlit run streamlit_app.py` (from `poc/`).
